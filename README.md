# Razorpay Landing Page Clone

A responsive front-end clone of the Razorpay official landing page built with modern web technologies, focusing on clean UI replication, layout structuring, and responsive design.
---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **CSS Tooling:** PostCSS, Autoprefixer
* **Icons:** [Feather Icons](https://feathericons.com/)

---

## ✨ Features

* **Pixel-Perfect UI:** Closely mirrors Razorpay's modern, product-focused landing page aesthetic.
* **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile screen sizes.
* **Component-Driven Sections:**
  * Navigation bar with desktop and mobile layouts
  * Hero section with call-to-action elements
  * Product suite showcases (Payment Gateway, Payment Links, Invoices, etc.)
  * Feature highlight grids and interactive hover states
  * Footer with comprehensive multi-column navigation links
